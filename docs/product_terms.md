# TheStage Apple SDK Product Terms

Legal / commercial terms for the on-device Apple SDK (iOS & macOS).

The full supplemental **TheStage Apple SDK Product Terms** live on the
documentation site (Sphinx), parallel to the QLIP and Elastic Models product
terms — page `apple-sdk-product-terms` on
[docs.thestage.ai](https://docs.thestage.ai/).

## What integrators need to know

| Topic | Summary |
|---|---|
| Product | TheStage Apple SDK — SwiftPM + Flutter plugin + TheStage engine bundles |
| Access | Requires an API Token; initialize before use |
| Seats | `(apiToken, deviceId)` — see [licensing.md](./licensing.md) |
| **Pricing** | **By arrangement** — open a **Service Request** at [app.thestage.ai/contact](https://app.thestage.ai/contact). No public rate card. |
| Redistribution | Governed by the Product Terms + master agreement; see shipped `LICENSE` |

Draft terms are modeled on TheStage’s other product-terms pages and should be
treated as binding only after TheStage legal/finance review.

## Agent checklist

- Link Product Terms for legal questions; do not invent rate cards.
- Device-seat product facts → [licensing.md](./licensing.md).
- Shipped package `LICENSE` points at these terms + contact for pricing.
